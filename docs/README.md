# Проект SkillSwap

## Архитектура

Проект строится по Feature-Sliced Design

- `app` - запуск приложения, провайдеры и глобальные стили
- `pages` - страницы приложения
- `widgets` - крупные блоки страниц, например Header и Footer
- `features` - действия пользователя и бизнес-функции
- `entities` - основные сущности проекта
- `shared` - общие компоненты, утилиты и настройки

Новые папки и модули создаются по мере появления задач

## Данные

### Тип UserId

Используется для описания уникального идентификатора пользователя

`UserId = string` - уникальный id пользователя

### Тип Gender

Используется для описания пола пользователя

`Gender = 'male' | 'female'` - пол пользователя

### Интерфейс User

Описывает пользователя SkillSwap. Данные используются для регистрации и входа, карточек в каталоге, страницы навыка, личного кабинета, фильтров и избранного

Поля интерфейса:

`id: UserId` - уникальный id пользователя  
`email: string` - почта для регистрации, входа и редактирования профиля  
`password: string` - пароль для моковой авторизации  
`name: string` - имя пользователя  
`avatarUrl: string` - ссылка на аватар пользователя  
`birthDate: string` - дата рождения в формате `YYYY-MM-DD`, из нее вычисляется возраст  
`gender: Gender` - пол пользователя  
`cityId: CityId` - id города пользователя  
`about: string` - информация о пользователе из личного кабинета  
`learningSubcategoryIds: SkillSubcategoryId[]` - id подкатегорий навыков, которым пользователь хочет научиться  
`likesCount: number` - количество лайков для сортировки раздела Популярное  
`favoriteUserIds: UserId[]` - id пользователей, добавленных в избранное  
`createdAt: string` - дата создания карточки для сортировки раздела Новое

Связи с другими сущностями:

- `cityId` связывает пользователя с `City`
- `learningSubcategoryIds` связывает пользователя с подкатегориями навыков
- `favoriteUserIds` связывает пользователя с другими пользователями
- предлагаемый навык хранится в `Skill` и связывается с пользователем через `authorId`

### Тип SkillId

Используется для описания уникального идентификатора навыка

`SkillId = string` - уникальный id навыка

### Интерфейс Skill

Описывает навык, которому пользователь может научить. Данные навыка используются в карточке пользователя, поиске, фильтрах и на странице навыка

Поля интерфейса:

`id: SkillId` - уникальный id навыка  
`authorId: UserId` - id пользователя, который предлагает навык  
`title: string` - название навыка, которое пользователь вводит при регистрации  
`categoryId: SkillCategoryId` - id категории навыка  
`subcategoryId: SkillSubcategoryId` - id подкатегории навыка  
`description: string` - подробное описание навыка  
`imageUrls: string[]` - ссылки на изображения для карусели

Связи с другими сущностями:

- `authorId` связывает навык с `User`
- `categoryId` связывает навык с категорией
- `subcategoryId` связывает навык с подкатегорией

### Тип SkillCategoryId

Используется для описания уникального идентификатора категории навыка

`SkillCategoryId = string` - уникальный id категории

### Тип SkillSubcategoryId

Используется для описания уникального идентификатора подкатегории навыка

`SkillSubcategoryId = string` - уникальный id подкатегории

### Интерфейс SkillCategory

Описывает категорию навыков, например Творчество и искусство

Поля интерфейса:

`id: SkillCategoryId` - уникальный id категории  
`name: string` - название категории  
`subcategories: SkillSubcategory[]` - подкатегории, которые относятся к категории

### Интерфейс SkillSubcategory

Описывает подкатегорию навыков, например Музыка и звук

Поля интерфейса:

`id: SkillSubcategoryId` - уникальный id подкатегории  
`name: string` - название подкатегории

Связи с другими сущностями:

- подкатегории хранятся в массиве `SkillCategory.subcategories`

### Тип CityId

Используется для описания уникального идентификатора города

`CityId = string` - уникальный id города

### Интерфейс City

Описывает город пользователя. Города используются при регистрации, редактировании профиля и фильтрации каталога

Поля интерфейса:

`id: CityId` - уникальный id города  
`name: string` - название города
